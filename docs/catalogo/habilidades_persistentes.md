# Habilidades persistentes

Mejoras que se conservan para siempre y valen en todos los escenarios. No se compran ni se ganan con las pruebas: se ganan al escapar de la pesadilla en el escenario que las tiene. `efecto_en_torre` es el boost equivalente que se aplica en la torre (ver boosts_y_consumibles.md); si está vacío, la habilidad actúa sobre el run (claridad inicial, lugares de consumibles, precio de reintentos...). Los números exactos viven en el código: si querés cambiarlos, indicá el valor nuevo en la descripción.
